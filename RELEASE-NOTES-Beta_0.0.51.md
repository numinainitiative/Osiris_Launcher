Osiris Beta 0.0.51

- Adds Trophies integration to Game Details and Edit Game, with a three-trophy preview and a full achievement list. Install Trophies 0.1.0 separately from Extensions.
- Adds clickable collections in Game Details. Collection pages reuse Home's hero, gradients and slideshow, with a library-style grid of member games.
- Moves vertical-library presentation preferences into the text-only Options menu, with compact sizing, edge spacing and clickable cursors.
- Adds General -> Starting Page, with Home, Library and Extensions choices.
- Shows the selected edition in sidebar and library-grid titles, and fixes per-edition local installation/archive management.
- Removes the retired edition-to-integrated-library pairing controls and behaviour, preserving legacy data without using the old links.
- Adds Open folder to the Screenshots Gallery game editor, including when the game has no screenshots or its details card is hidden.

Update Osiris first, then install Trophies 0.1.0 and update Exophase to 0.2.7 and Xbox Library to 1.0.2 where installed. Steam Library 1.0.3, Stats 0.1.3, Game Gallery 2.0.4 and Screenshots Gallery 0.1.0 remain current; no replacement releases are needed.

Trophies imports a chosen Steam catalogue. Local games use manual Game Edit -> Trophies -> Sync through their saved Exophase editions; integrated Steam/Xbox games use their respective connected libraries. Website access or unmatched platform-specific achievements can limit synchronisation. Xbox achievement access still requires live-account acceptance testing. Local in-game unlock detection and notifications are not included.

Existing Data, settings, screenshots and extension state are preserved by the normal updater. Release archives contain no user profiles or credentials. The inherited Playnite program-update channel remains disabled.
