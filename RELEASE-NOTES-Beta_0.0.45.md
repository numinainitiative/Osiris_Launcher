Osiris Beta 0.0.45

- Adds the new Home dashboard with greeting, time and date, recent and favourite games, weekly activity, responsive cards, launch actions, and Home Page settings.
- Reworks the sidebar into a live installed-extension index with correct global-page navigation, settings fallbacks, update actions, and guarded uninstall handling.
- Adds first-class support for the Stats extension and refreshed Game Gallery and Stats artwork throughout the interface.
- Includes the latest extension-page navigation, responsive layout, typography, and visual fixes accepted in Development.

Stats, HowLongToBeat, Exophase, Game Gallery, and Steam Library updates are distributed separately through their extension releases. This portable beta keeps existing installation data in its own Data directory, and the inherited Playnite program-update path remains disabled.
