Osiris Beta 0.0.48

- Adds a customizable Home dashboard with a focused edit mode, directional card reordering, removable and restorable cards, and profile-local saved layouts.
- Adds Last Played and Recently Added Home cards alongside an optional Weekly Stats card whose individual metrics can be selected from the add-card menu.
- Connects Home to the Stats extension for live weekly play time, new games, favourite play time, average session, trophies earned, and most-played game values.
- Matches the Home Weekly Stats tiles to the Stats page card system and preserves the normal card content layout while editing, with equal edit footprints and clear dashed boundaries.
- Fixes the installed Osiris executable icon and corrects the Osiris and Exophase artwork used by update notifications.
- Includes the accepted Home spacing, sizing, card-capacity, and editing refinements completed in Development since Beta 0.0.47.

This portable beta preserves existing installation data in its own Data directory. Extension packages remain independently versioned, and the inherited Playnite program-update path remains disabled.
