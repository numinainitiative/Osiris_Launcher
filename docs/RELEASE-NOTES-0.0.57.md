Osiris Beta 0.0.57 improves edition editing and page mirroring.

- Add and delete editions from the bottom bar in Game Edit. New editions start as independent profiles. Deleting the selected edition preserves its siblings and game files.
- Switching editions retains unsaved changes. Save applies the edited drafts; Cancel discards them.
- Use Copy page for a one-time copy, or enable the page mirror switch and choose a source edition for shared information. Mirrored pages show a green link icon at the right of their navigation label.
- Every page can mirror except Installation and Danger Zone. Advanced shares played time, play count and activity while game IDs and library/database identities remain unique.
- Media, Gallery, Screenshots Gallery, Stats Insights, HowLongToBeat, Exophase and Trophies support their scoped shared pages. Disabling a mirror preserves an independent copy.
- Restored the Danger Zone navigation label and kept the edition controls on one row.

After updating Osiris, update these extensions from Extensions: Game Gallery 2.0.6, Screenshots Gallery 0.1.3, Stats 0.1.5, HowLongToBeat 1.2.6 and Exophase 0.2.9. Trophies 0.1.2 remains current.

Existing editions stay independent unless mirroring is explicitly enabled. User Data, games, settings and screenshots are preserved. The inherited Playnite program-update channel remains disabled.
