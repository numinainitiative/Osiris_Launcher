Osiris Beta 0.0.56 adds optional shared pages between editions.

- Use Share page beside Copy page in Game Edit to keep General, Advanced, Actions, Links, Scripts or Trophies synchronized between selected editions.
- Choose the source edition and Save. Cancel discards the pending link; Stop sharing keeps an independent copy.
- Advanced can share playtime, play count, last played and its other editable values. Profile identities, library ownership and installation remain separate.
- Trophies 0.1.2 shares catalogue settings and earned progress, preserving the connected library source. Update Trophies from Extensions after updating Osiris.
- Removing a shared edition preserves the surviving edition and its trophy catalogue.

Existing editions stay independent until sharing is explicitly enabled. Your Data, games, settings, screenshots and extension data are preserved. The inherited Playnite program-update channel remains disabled.
