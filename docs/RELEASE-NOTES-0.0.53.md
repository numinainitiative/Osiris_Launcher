# Osiris Beta 0.0.53

- Fix inconsistent font sizes and font-family restoration across the footer,
  edition selector and game descriptions. Overview text matches Details fields.
- Centre game logos above the Play panel with more vertical room and spacing.
- Refine Home's edit mode with square dashed outlines, directional controls
  and a larger red remove button. Refresh the Last Played clock icon.
- Add Game Details card layout editing with the same directional controls,
  staged Save and responsive ordering, without card deletion.
- Support nested extension-page Back navigation, including Fun Games Roulette.

Fun Games 0.3.2 is available separately from Extensions: a horizontal Roulette,
saved custom roulettes, a management menu, import/export and winner celebrations.
Update Osiris before installing Fun Games for complete nested-page navigation.

Existing library, settings, screenshots and extension data are preserved.
The inherited Playnite program-update channel remains disabled.
