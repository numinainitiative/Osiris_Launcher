# Osiris Beta 0.0.34

This release brings the current Osiris Development build to the public beta.

- Fixes the first-run Library layout so newly added games immediately use the
  selected multi-column grid.
- Bundles the complete Rajdhani font family so Osiris keeps its intended
  typography on every installation.
- Uses game logos consistently on the details page instead of substituting game
  icons.
- Refines the first-launch welcome experience with feature galleries and updated
  screenshots.
- Shows notification popups only for newly observed unread notifications and
  lets each popup open the Notifications page.
- Adds the missing restart marker to Navigation Panel width settings.
- Adds Ko-fi alongside Patreon in Contacts & Links.
- Updates the public Game Gallery extension to version 2.0.2, restoring its
  settings page and including the latest gallery reliability improvements.

Download `Osiris-Beta_0.0.34-win-x64.zip`, extract it to a writable folder, and
run `Osiris.exe`. Existing installations updated through Osiris preserve their
`Data` directory.
