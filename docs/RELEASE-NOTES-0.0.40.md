# Osiris Beta 0.0.40

This release introduces global pages for installed extensions.

- Adds an Extensions section to the navigation panel and shows extension pages
  in the same precise list layout used for games.
- Opens the Extensions catalogue without preselecting an installed extension;
  an extension page is selected only after it is clicked.
- Hosts extension-owned pages beneath Osiris's fixed native header and search
  panel.
- Lets extension work use the standard bottom update panel for progress,
  cancellation, and completion feedback.
- Adds the host integration used by HowLongToBeat 1.2.0's global game-library
  page.
- Preserves existing games, settings, extensions, and all other files in `Data`
  during the update.
