# Osiris Beta 0.0.39

This release polishes Game Details and its HowLongToBeat integration.

- Keeps the Overview description visible while Osiris is idle.
- Fixes the oversized HowLongToBeat logo in update notifications.
- Matches the Details and Links content surfaces to the Overview background.
- Gives every Game Details "view more" footer the same background treatment.
- Preserves existing games, settings, extensions, and all other files in `Data`
  during the update.
