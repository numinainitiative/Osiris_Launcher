# Osiris Beta 0.0.38

This release introduces the original HowLongToBeat extension and finishes the
responsive Extensions experience.

- Adds HowLongToBeat to the public extension catalogue, showing Main Story,
  Main + Extras, and Completionist estimates on Game Details.
- Adds per-game HowLongToBeat controls in Edit Game for enabling the card and
  choosing the correct search result manually.
- Adds the standard extension settings and Danger Zone flow for HowLongToBeat.
- Keeps Browse extension cards evenly spaced and aligned with the category and
  sort controls while preserving responsive row wrapping.
- Applies the same responsive wrapping to every populated Installed category,
  preventing installed cards from being compressed or clipped on narrower
  windows.

Existing games, settings, extensions, and other files in `Data` are preserved
during the update.
